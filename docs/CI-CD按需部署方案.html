1 阶段一：无服务器模式（当前可用）

阶段一 — CI 代码检查 + 本地测试 ● 运行中

无需任何服务器成本，完全免费。GitHub Actions 提供每月 2000 分钟免费额度（私有仓库），足够日常开发使用。

1.1 CI 自动检查（GitHub Actions Runner）

触发条件：push 到 main/develop 分支，或创建 PR

执行内容：

✓ ESLint        代码规范检查
✓ Prettier      格式一致性检查
✓ TypeScript    类型安全检查
✓ 结构验证      项目文件完整性
✓ 构建产物      上传 Artifact（7天保留）

1.2 本地 Docker 测试环境

安装 Docker Desktop 后，一键启动测试数据库环境：

# 启动 PostgreSQL + Redis（测试凭据，无需密钥）
docker compose -f docker-compose.test.yml up -d

# 完整构建测试（含应用镜像）
docker compose -f docker-compose.test.yml --profile full up -d --build

# 连接测试数据库
docker exec -it splitter-test-pg psql -U splitter_test -d splitter_test_db

# 清理
docker compose -f docker-compose.test.yml down -v

1.3 本地一键验证

与 CI 完全一致的检查，本地几秒完成：

npm install
npm run verify

等价于依次执行：lint → format:check → type:check → test:ci

1.4 手动触发 CD 构建验证

GitHub → Actions → CD - 构建与部署 → Run workflow → 选 test

构建 Docker 镜像验证 Dockerfile 可用性，部署步骤自动跳过，无需任何 Secrets。

5 GitHub Secrets 配置清单

购买服务器后，在 GitHub 仓库 → Settings → Secrets and variables → Actions → New repository secret 中逐一添加：

🔑
DEPLOY_HOST
服务器公网 IP 地址，例如 123.45.67.89
👤
DEPLOY_USER
SSH 登录用户名，例如 root 或 ubuntu
🔐
DEPLOY_SSH_KEY
SSH 私钥全文（-----BEGIN RSA PRIVATE KEY----- 开头到 -----END RSA PRIVATE KEY----- 结尾）
🌐
DEPLOY_DOMAIN
域名（可选），例如 splitter.example.com，用于 Nginx 配置和健康检查

生成 SSH 密钥对：

# 在本地生成（回车跳过 passphrase）
ssh-keygen -t rsa -b 4096 -f ~/.ssh/splitter_deploy

# 公钥复制到服务器
ssh-copy-id -i ~/.ssh/splitter_deploy.pub root@你的服务器IP

# 私钥内容粘贴到 GitHub Secret DEPLOY_SSH_KEY
cat ~/.ssh/splitter_deploy

6 服务器初始化步骤（购买后执行）

  1. 购买服务器 — 选择上方任意服务商，2核4G起步，Ubuntu 22.04 LTS
  2. 域名备案（国内服务器必须） — 微信小程序要求 HTTPS + 已备案域名
  3. 生成 SSH 密钥 — 本地生成密钥对，公钥放入服务器 ~/.ssh/authorized_keys
  4. 配置 GitHub Secrets — 添加 4 个密钥（见上方清单）
  5. 服务器安装 Docker 
    curl -fsSL https://get.docker.com | sh
systemctl enable --now docker
systemctl enable --now docker compose
  6. 上传 .env.production — 在服务器创建环境变量文件（数据库密码、JWT密钥、微信AppID等）
  7. 触发首次部署 — GitHub Actions → CD workflow → Run → 选 production
  8. 验证健康检查 — 访问 https://你的域名/health 返回 200
  9. 配置微信白名单 — 微信公众平台 → 开发管理 → 服务器域名填入 API 地址
  10. 小程序编译上传 — HBuilderX 编译 → 微信开发者工具上传 → 提交审核

7 切换检查清单

阶段一 → 阶段二切换（购买服务器时）

  • 已购买云服务器（2核4G+）
  • 域名已完成 ICP 备案
  • SSL 证书已申请（Let's Encrypt 免费）
  • SSH 密钥对已生成，公钥已上传服务器
  • GitHub Secrets 已配置（4个）
  • 服务器已安装 Docker + Docker Compose
  • .env.production 已创建并上传到服务器
  • 手动触发 CD workflow 选 production 成功部署
  • 健康检查 /health 返回 200
  • Nginx 反向代理正常（HTTP → HTTPS 重定向）
  • PostgreSQL 数据库初始化完成（Prisma migrate）
  • Redis 连接正常
  • 微信小程序服务器域名已配置白名单
  • 小程序编译上传并提交审核

阶段二 → 阶段三切换（稳定运行后）

  • PM2 进程守护已配置
  • 日志轮转已配置（避免磁盘写满）
  • PostgreSQL 自动备份脚本已配置（crontab）
  • 备份文件保留 7 天滚动
  • 回滚脚本 scripts/rollback.sh 已验证可用
  • 操作日志审计正常（sys_operation_log）
  • 告警通知渠道已配置（邮件/钉钉）
