# 分光器资源管理系统\_业务错误码

> 说明：
>
> 1. HTTP 状态码负责网络、鉴权层；业务错误码取自响应体 `code` 字段。
>
> 2. AI‑Agent 收到非 0 业务 code，必须使用文档给定对外话术返回终端用户，**禁止输出堆栈、SQL、数据库字段、内部技术细节**。
>
> 3. 响应固定结构：`{"code": number,"msg":"内部原始msg","data": any,"showMsg":"对外展示话术"}`
>
> 4. 0 代表业务成功；业务异常全部返回非 0 code；Agent 禁止编造虚构业务数据，无数据如实告知用户未查询到匹配数据。

## 特殊约束说明

1. 账号、微信 openid 全局永久唯一（包含逻辑删除数据），冲突直接抛出`1003 数据重复`，不复用额外错误码。

2. 所有拓扑校验、状态联动校验、数据权限校验与数据库设计文档一一对应。

3. Agent 禁止解析 msg 内部字段，全部对外输出统一使用`showMsg`字段内容。

4. 批量操作发生多条业务错误时，优先返回第一条错误；不做批量拼接返回。

## 附：操作日志枚举说明

操作日志字段使用中文枚举值：

- `operation_type`（操作类型）：登录 / 登出 / 新增 / 修改 / 删除 / 权限分配 / 角色变更 / 故障上报 / 故障恢复

- `target_type`（操作对象类型）：用户 / 社区 / 分光器 / 权限

> 注：行政区划 `sys_region` 由后台导入脚本维护，不走业务操作日志，`target_type` 不含"行政区划"类型。
