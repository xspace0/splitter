### 发现的额外缺陷（本轮未修，属先前遗留代码）

`web/src/views/ProfileView.vue:132` 与 `MainLayout.vue:108` 把 `res.data` 直接当作解包后的用户对象
（`profile.value = res.data`），但 `request.ts:23` 的拦截器返回的是**后端信封** `{code,message,data}`，
正确写法应为 `res.data.data`。同文件第 133-134 行读 `res.data.username` 同样取不到值，
会导致个人中心姓名/手机号显示为空。`:119` 的 `profile?.username` 因此恒为 `undefined`。

> **环境说明**：`vite build` 与 `jest` 在本机会因沙箱禁止派生管道子进程而报 `spawn EPERM`；`vite build` 已通过放宽权限验证成功，`jest` 通过 `maxWorkers: 1` + `cache: false` 配置规避。二者均非代码缺陷。
